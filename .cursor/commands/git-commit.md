# git_commit

Добавить, закоммитить и залить изменения в репозиторий.

---

### 🧠 Описание
Автоматически выполняет последовательность:
1. `git add .`
2. `git commit -m "<сообщение>"`
3. `git push`

---

### ⚙️ Аргументы
| Имя      | Тип     | Обязательно | Описание              |
|-----------|----------|-------------|------------------------|
| message   | string   | ✅           | Сообщение коммита     |

---

### 💻 Команда

```bash
git add .
git commit -m "{{message}}"
git push
